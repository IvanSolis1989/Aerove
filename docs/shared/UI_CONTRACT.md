## 交付标准

两版的共同界面、交互和客户端功能必须一致。Lite 不是裁剪界面或功能的授权。开发尚未完成、首版进度、缺少现成 JNI/API、实现成本或所用 UI 框架不同，都不是可接受的发行差异。

唯一允许暂缓的是固定版本 Rust 核心确实不支持的能力。每项例外必须记录能力标识、固定核心 SHA、相关源码路径及行为证据、受影响的配置字段和功能入口。可在客户端或宿主桥接中实现的能力不能仅因缺少现成 API 就记作内核不支持。例外只存开发记录；APP 不出现未实现项、占位开关、灰置入口或开发清单。

无法提供核心限制证据的差异一律属于交付阻断，必须实现并验证，不能作为 Lite 特性删去。导入含不支持语义的配置须明确指出字段路径和原因，不静默删除或忽略。产品不能把功能减少或画质降低记作性能收益。

## 双向维护

任何一版对共同 UI、交互或功能做调整，都必须同时评估并同步另一版。该规则同样适用于字体、间距、图标、圆角、状态信息、卡片层次、开关、导航、弹层、加载/失败/空状态、动画以及无障碍；没有“小幅微调无需同步”的例外。

实现遵循同一份设计和行为契约，保留各平台实现边界，不将 Flutter 控件直接打包到 Lite，也不强迫核心共用运行时。修正某一版对既有契约的偏离时，另一版作为正确基线复核，不为满足“双向”而制造无意义的对应改动。

共同变化的完成记录必须包含：受影响功能/组件、两版源码路径与最终 diff、状态和交互对照、相关测试、实际渲染来源，以及仍有效的核心例外。更新说明只描述实际完成的行为。仅仅改过两个文件或通过静态映射检查不能证明已一致。

同功能的刷新频率、数据抓取次数、缓存有效期、请求合并、失败退避和前后台暂停规则须与标准版对齐。优先事件驱动和共享订阅，避免 Lite 增加轮询或重复抓取；动画和可见数据更新随可见生命周期停止。平台实现可以不同，但新增重绘、CPU/网络工作必须有具体原因和验收证据，不能把精简功能或降低画质记作能效收益。

品牌启动背景覆盖整个窗口及系统栏，标准版始终黑底亮飘带，Lite 始终白底黑飘带。系统浅深色设置不得改变启动品牌底色，图标外不能露出不同底色的方块。产品名称、品牌反色和系统必要权限提示是已确认的产品/平台区别，不放宽共同界面要求。

## 功能覆盖与运行闭环

对照范围是标准版 Android 当前真实可达的全部客户端功能，不是早期首版清单或某次截图中出现的按钮。
桌面专用窗口、托盘和 Helper 继续由标准版维护，不要求 Lite 在 Android 模拟桌面进程；Android 共同能力不能因此省略。

| 责任域 | 必须核对的共同能力 |
| --- | --- |
| 仪表盘与出站 | 状态信息、大控制按钮、分层卡片、卡片增删排序与持久布局、上传/下载、三模式、VPN/局域网信息、真实出口、服务检查、IP 质量、内存及详情 |
| 配置与订阅 | 本地/链接/分享/扫码导入、更新与取消、名称和属性编辑、文件替换、源配置编辑、真实运行配置只读预览、选择与删除、资源及更新策略 |
| 节点、策略与规则 | 节点/策略组选择与展示、测速及超时/取消、provider/规则集管理、规则/全局/直连、实际路由与连接归属 |
| 网络与系统 | DNS/IPv6、端口和局域网访问、分应用、网络变化、启动/常驻/权限、TUN/protect、运行中接管及启停/重启的最新意图收敛 |
| 观测与维护 | 连接/流量及关闭、日志/DNS 观测、诊断、脚本、备份/恢复与 WebDAV、故障恢复和用户数据安全 |
| 呈现与设置 | 全部共同设置及其默认值/迁移、语言、主题/自定义色、字体、导航、菜单/弹层、编辑器行为、加载/空/失败/禁用状态和无障碍 |

每项功能按“用户入口 → 动作 → 持久状态/真实核心或宿主 → 结果读回”核对，包含错误、取消、并发切换和恢复。
只有仓储函数、JNI 方法或测试 fixture，没有生产路由和真实供数，仍属于未完成。源配置不能冒充运行配置，配置 ZIP 导入不能冒充应用备份。
不同运行时的内部指标须说明口径；Rust 内存不得伪装成 Go 堆/GC，进程 RSS/PSS 不重复计数，不用固定零值或演示数据补齐状态卡。

## 外观与交互细节

[外观规范](appearance.md)定义三档材质及前景取色；[工程规则](../../.agents/rules.md)定义连续圆角和字体层级。
原生实现须映射相同视觉和行为，不以 Android 默认圆角、字号/字重层级、开关或控件布局代替。

- 核对状态卡/大按钮的层次和比例、旗面居中、图标字形、间距、分隔、卡片展开/吸顶、选中与按压反馈。
- 主题预设、自定义色、四种配色策略、系统/浅色/深色、高对比度与纯黑规则须对应；保存、取消和迁移不能擅自覆盖用户选择。
- 极光构图、换色/换图、持久种子、日切换及减少动态效果遵守共同门禁；不得通过每帧随机化或重复采样制造差异。
- 背景只在正确层捕获和共享，不能把前景文字、摄像头或嵌套玻璃重复采进背景，不能用叠加模糊掩盖清透错误。
- 核对返回、键盘、焦点/选择菜单、长按、拖动、动画反向、过渡遮挡、旋转/重建、大字体和屏幕阅读器。

## 仪表盘融合布局

2026-10-24 用户选择第二版布局并授权实现，当前为待完成实现与实际 Android 渲染验收的新共同规格。

- 状态与网络速度共用主卡：保留出口身份、质量、组织、运行时长和大控制按钮。2026-10-26 用户比较实际 Flutter 试排后，确认两版 Android 在空间充足时将速度置于右下附加层，仅竖排两行“↑ 速度”“↓ 速度”，使用 10 逻辑字号、常规字重；不显示 Upload/Download 标题或累计流量。两行文字中心分别与左侧 footer 标签、数值行中心对齐，右侧以卡片实际 R 角圆心对应的安全边距定位，不能用估计常量造成偏心。
- 空间充足时，速度附加层不参与主 header/body 的测量。相对于无附加信息的共同状态布局，IP、国旗、质量、组织、运行时长、大控制按钮的 Rect 及卡高保持相同。两版 footer 都采用运行时长、组织各一格的标签与数值结构。箭头使用 UI 字形资源，数字及单位与箭头遵守同一套前景透色和对比度保护；保留完整方向、数值、单位与本地化读屏语义，不添加累计朗读，不用省略号隐藏速度。
- 仪表盘状态卡的飘带与独立网速卡两版均删除，启动品牌飘带保留。旧布局解析保持兼容，仅从呈现与编辑成员中滤除独立网速项，保留其他隐藏选择与顺序。真实双通道曲线和填充在主内容下层，沿整张卡片底边闭合，覆盖 footer 后方，不得在中部截断或留下整条空白底带。保留原版背景、曲线与前景文字的层次，材质和填充连续，文字自然覆盖下层曲线；不增加文字局部遮罩、挖空、衬底或新效果。不能出现文字周围的矩形／圆角浅色块，不能另加图表区或拉长正常卡片。
- 首个真实样本在当帧形成有效曲线，零流量自然回落，缺样本不生成随机浪。实际文字和箭头墨迹须避开主内容与按钮的绘制轮廓，透明触摸区域不算绘制占用；不能挪动主内容、测试标签或隐藏关键量值绕过检查。桌面四列状态卡占满首行并保留原卡高。Android 确有遮挡时优先使用同排相邻空位；实际空间不足时（包括已确认的 360dp、1.15 倍字体高速度值场景），允许将完整两行速度追加在主内容底部，卡片自然增高，不以字体倍率大于 1.3 为前提。追加时 footer 两行中心对齐约束随自然空间例外处理，原正文和按钮的位置、字号保持不动；不得为腾位缩小速度字号、隐藏或四舍五入速度值。此例外仅按实际空间不足触发，不默认拉高所有状态卡。可读性、隐私遮罩及减少动态效果优先。
- 国旗收回原有蠕动气泡内部，恢复 beta.5 之前的比例，检测出口时保留气泡运动。旗面无边或外缘渐隐，去除硬圆裁切、常态描边、独立底座和阴影，保留语义、重试与隐私行为。中心旗面保持清楚，只对外缘轻微羽化；停稳后完整旗面居中，不因旗面内部图案偏左而移动整旗。
- 网络控制卡只有同一行的三个等宽完整胶囊：第一个每次点击按规则→全局→直连循环，第二个切换 VPN 偏好，第三个切换局域网代理偏好；删除下方旧开关行、Enabled/Disabled 副文和 IP／复制行。三档材质的形状一致，图标与文字组按真实墨迹居中。中日文在合法字素边界断行，俄文及拉丁单词不硬切；优先两行和缩小内部留白，仍不足时所有候选统一适配，实际字形不低于 11 逻辑字号。保留独立的 VPN、LAN 状态含义、禁用与可访问反馈，不能合成总开关；真实监听信息仍由对应设置和详情入口提供。
- 启停水滴保留原 88dp 控制区域、轮廓和触摸目标，内部图标画布为 29.92dp 并居中，不继承外层最小尺寸；标准版已有正确的松约束居中行为时复用，不为同步制造改动。
- 网络概览上部保留服务四格、状态和按需刷新，下部保留实时连接、最近请求、DNS 查询三个独立详情入口。合并表面不合并刷新任务：服务检查保持按路由和手动触发，连接只取轻量摘要，请求与 DNS 复用真实事件计数。
- 配置/订阅与策略组继续独立。旧卡片隐藏选择、排序及平台适用性按原持久列表保留，以运行时分组投影呈现；不为融合强制恢复隐藏子模块或丢失旧布局。编辑器仍能管理原细分成员。

用户已确认 Lite beta12 真实 Android 十二图的外观方向，功能及帧验收仍须完成。后续 beta14 实际矩阵取得 8 格门内与 1 格晚帧，另 3 格清透缺图；1.3 倍中英文的字形、主内容几何和累计语义检查已通过，服务格大字体检查失败已进入修复。beta15 的控制布局、图标及服务格修正仍待新 Android、Flutter 及 APK 证据；旧图和模块检查不代替新候选确认或首发验收。

本节不代表已实现或已通过；完成须提供两版入口、数据流、取消/恢复与可见性证据，以及实际 Android 三材质×普通/极光×浅深色渲染。设计生成图不能替代实际运行图。

## Android 字体

两版默认跟随设备当前的系统字体，尊重厂商主题设置。APK 不捆绑正文、编辑器或 emoji 字体文件；编辑器使用系统等宽字体并保留系统中文回退。图标资源保留各自用途，不作为可选文字字体。

字体列表只展示已安装且实际主字体同时覆盖基本拉丁字符和共同固定常用中文样本的字体。直接检查实际字体文件及 TTC face 的 cmap；不能把系统 fallback 补出的字形当作候选字体自身覆盖，也不能按字体名称猜测。默认系统项始终可用，筛选结果为空不等于设备未安装字体。

旧选择失效时按系统字体显示，不持久覆盖用户原选择；字体恢复可用后重新核验。扫描和缓存有界、可取消且离开 UI 线程，不轮询或预加载全部字体。字体设置改变后的冷启动须读取当前系统配置；进程存活期间的厂商热替换能力按实际平台证据说明，不能自动重启 VPN 来刷新字体。

## 刷新、采集与生命周期

共同实现记录每个数据源的触发原因、更新间隔/缓存期限、共享订阅者、并发上限、取消和前后台行为；实际参数以已验证的标准版实现为基线。
改变参数时同时说明两版对应点与验证结果，不能在某一端私自增加一个统一的定时轮询代替原有按需策略。

- 可见页面共享已有流量、连接、路由和资源订阅；摘要不为了一个数字重复拉取完整大列表。不可见、不透明遮挡和后台状态停止无意义采集/动画。
- Android 通知栏或系统权限框造成短暂失焦时，立即暂停界面只读采样、投影和呈现需求；回焦点补当前快照，沿用原采样周期。失焦不关闭控制会话、不取消用户动作、资源清理或订阅维护，不影响 VPN 转发，也不触发失败探测重试。本 App 自有 Popup 以真实窗口焦点登记，不因编辑器仍打开而永久豁免失焦。
- 暂停呈现工作不暂停 VPN 转发、必要通知或用户已授权的后台工作；这些继续由服务所有者按共同策略管理。
- 因 Wi-Fi 排除规则而停泊时，两版保留静默前台通知以监听网络变化并自动恢复；正常 VPN 实际就绪后撤回额外 App 通知，代理模式保留必要通知。停泊、恢复、重复系统启动、手动停止和撤销均由同一服务所有者收敛，旧会话清理不能覆盖较新的启动意图。
- 路由、配置、核心实例变化后旧请求失效，退出页面、撤销权限、停核和销毁宿主及时取消任务；旧结果不能覆盖新意图。
- UI 重建不能重启运行中的 VPN；保留单一服务状态所有者、fd/protect 生命周期、资源 generation 和原子持久化边界。
- 出口、IP 质量和服务检查复用路由命中结果：出口不变不重测，普通稳定等待 1.5s、已有路由移动等待 300ms，同目标 5s 节流。页面激活、未被不透明路由遮挡且对应卡片在视口内时才观察；详情页可独立持有需求。失败项只在 hidden/paused 或 ON_STOP 后真正回到前台时重试，不因短暂 inactive 或标签重建重复探测。
- 保活但不可见的计数、表格和列表只记最新值，不排无效呈现帧，重新可见立即补齐。请求、DNS 与日志呈现按 300ms 合并，滚动交互期间为 600ms；连接摘要每 2s、完整列表每 1s，按可见需求共享。停止后读到零计数或空列表即休眠，重新启动恢复；暂时隐藏保留旧值，不额外清空。
- 壁纸、国旗和启停气泡、订阅用量液面共用 15fps 静止／10fps 交互节拍，交互信号不依赖极光开关；离屏或不可见的呈现动画停止推进。减少动态效果不改变真实运行状态和必要数据清零。
- 半透明菜单或弹窗打开时，后面仍可见的极光继续缓动；完整不透明页面、真实窗口失焦及既有后台门禁仍暂停背景。此规则不放开被遮挡的列表采样或订阅液面，也不改变三档材质、减少动态效果和原动画节拍。
- 资源与订阅采用 20 分钟前台维护顺序，先订阅、后资源；启动执行一次，核心首次可用时补跑此前跳过项。provider 按自身 interval 更新，内容及编译输入不变时不生成新资源代际、不重载、不重启；规则文件变化优先原地重载。自动失败退避两版使用同一时间表，取消不计失败，手动更新、成功、源编辑及网络或核心会话变化清零。
- 底层网络变化优先热切换，句柄变化关闭旧连接；只有实际写入 TUN Builder 的物理 DNS 列表变化且不能热改时才重建接口。无网络或 LinkProperties 尚未到达不伪造错误，旧失败和晚到结果不能污染当前会话。
- 解析、大文件/备份、图像解码、网络请求和数据规模相关计算离开 UI 线程；缓存和任务有界，不以无限保活、内存增长换取表面流畅。
- 性能验证比较同画质、同功能、同配置与数据负载。JVM、静态源码、编译成功或模拟器图像都不能证明真机省电。

## 变更与并行协作

任何共同改动在完成记录中列明两版受影响入口、已有实现与剩余差异；当前审计和失败记录不能通过改名为“核心不支持”或归档隐藏。
规范先于完成声明，但规范更新本身不代表实现已达标。只修改一端且另一端仍有共同能力缺口时，报告未完成，不宣布全功能一致。

可将不重叠的 UI、数据、内核或验证责任并行交给 Agent；派单必须带本契约、固定来源、唯一写集及验收条件。
主线程负责生产路由和共享依赖整合，稳定 checkpoint 后再复核，禁止同文件多写者和各自重复触发全量 CI。
