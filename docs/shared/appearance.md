# Aerove 外观与特效规则

适用范围：两版共同的有效规格。本页约束优先于产品调研和历史资料；规格更新不代表实现或验收已经完成。

本页目录：[六种组合](#六种组合) · [部件职责](#部件职责) · [优先级与实现](#优先级与实现)

外观档位和底图独立选择。「灵动极光」是原「随机渐变底图」的新名称，不更改已保存的开关、配色或构图。

## 六种组合

### 简约纯色

| 底图 | 表面与交互控件 | 文字与图标 |
| --- | --- | --- |
| 普通主题色 | 主题实色，无玻璃光学 | 原主题颜色 |
| 灵动极光 | 保留极光底图，控件仍为实色，无模糊和折射 | 普通及选中图标弱透色；黑白控件底与其文字保留可读性 |

### 柔光磨砂

| 底图 | 表面与交互控件 | 文字与图标 |
| --- | --- | --- |
| 普通主题色 | 透色模糊，不折射、不色散、不画玻璃边缘光 | 当前主题色与对比度保护 |
| 灵动极光 | 透色模糊，不折射、不色散、不画玻璃边缘光 | 随极光柔和取色 |

### 流光清透

| 底图 | 表面与交互控件 | 文字与图标 |
| --- | --- | --- |
| 普通主题色 | 透明折射与玻璃边缘光，保留主题配色 | 当前主题色与对比度保护 |
| 灵动极光 | 透明折射与玻璃边缘光 | 随极光取色并保护对比度 |

柔光磨砂覆盖正文、顶栏、底部导航、菜单、弹窗、滚动提示和开关。顶栏与底部导航不再保留清透例外。不同尺寸部件可有不同模糊半径，但不能在此档位混入折射或独立玻璃描边。

## 部件职责

- 卡片与弹层提供表面；静态子区域沿用其表面层级，不因嵌套重复添加整块玻璃。
- 开关的轨道和滑块各自遵循所选材质，包括常规设置、配置编辑、仪表盘和弹层中的开关。磨砂滑块透出底图，不能退化为白色实心圆。
- 网络控制的模式循环、VPN、局域网代理在三档材质下均为等宽完整胶囊，图标和文字组居中，各自保留材质与独立按压反馈，选中项以轻微主题色填充区分。模式胶囊按规则→全局→直连循环；切换材质档位不改节点或代理状态。
- 融合主状态卡、网络控制卡和网络概览卡使用同档位外框；启停气泡保留其轮廓；国旗采用无边或外缘渐隐，去除外圆底座、阴影、常态描边与硬圆裁切，保留尺寸、位置、语义、重试和隐私行为。中心旗面清楚，必要时仅外缘轻羽化。速度线和填充位于文字与按钮下层，沿整卡底边闭合，材质与填充连续。文字保持原版前景层次，不增加局部遮罩、挖洞或衬底；不留浅色文字块、整条 footer 空白或独立图表区。状态卡飘带删除，启动品牌飘带保留。国旗停稳后按完整旗面边界居中，不移动旗面内本来偏左的图案。
- 两版 Android 空间充足时，右下角速度只保留竖排的 UI 上／下箭头与完整速度，10 逻辑字号、常规字重；两行中心对齐左侧 footer 的标签、数值行，原主内容、按钮和普通卡高保持不变。实际空间不足时（包括 360dp、1.15 倍字体高速度值场景），允许完整两行追加在主内容底部并自然增高，footer 对齐随自然空间例外处理，不以字体倍率大于 1.3 为前提，也不默认拉高卡片。原正文不移动，不为腾位缩字号、隐藏或四舍五入速度值。箭头、数字及单位仍沿用相同前景取色，在玻璃／极光下透色，高对比及纯色按既有规则保护可读性，细节以[仪表盘融合布局](UI_CONTRACT.md#仪表盘融合布局)为准。
- 图标、文字、进度线和焦点框不等同于一块独立玻璃面板。状态颜色、键盘焦点与选中语义仍需清楚可辨。
- 代理组标题与展开主体维持同一外轮廓；滚动置顶、组尾退出和展开收回都不能露出方形页色或在接缝处形成药丸断层。

## 优先级与实现

高对比度、纯黑深色的实色回退优先于外观档位。减少动态效果与应用进入后台继续遵守原有动画门禁，背景不持续渲染。

半透明菜单或弹窗后的可见极光继续缓动；完整不透明遮挡、真实窗口失焦与后台按共同门禁暂停。自有 Popup 依真实焦点登记，不能用页面仍挂载代替窗口有焦点；三档材质均遵守同一规则，不放开其他被遮挡内容的采样或动画。

`LiquidGlassScope` 与 `AuroraAppSurface` 分别控制光学开关、前景取色和底图。`LiquidGlassStyle.forQuality` 解析材质，宿主对低层直接绘制应用同一规则；独立边缘装饰在最终合成和背景回放时也遵守质量门禁。

磨砂导航的选中背景叠加轻微底色以保留层次，文字和图标通过 `GlassInkBackground` 按同一底色计算对比度；拖动时按透镜实际覆盖区域生效，不只按已选中的索引判断。

验证覆盖六种组合、深浅色、开关两种状态、菜单和导航、档位往返切换，以及窄屏和宽屏。像素对照与实际入口渲染用于核验效果，组件数量断言只作辅助。
