# AEROVE Lite 变更记录

## 待发布

本轮待发布候选为 **0.1.0-beta.16（安装编号 16）**。0.1.0-beta.15/code 15 仅为未发行历史候选，已由本候选替代；此处不表示已生成或验收 beta.16 APK。保留独立包名 `dev.aerove.lite`、原签名和更新入口；安装编号按 VERSIONING 从 15 递增至 16。内核来源为固定 meow-rs v0.26.1，迁移及例外证据见 [核心记录](core/meow-migration.md)。

- 与标准版同步完整胶囊、居中的图标文字组合及整行居中的局域网地址；移除重复的 Enabled/Disabled 副文和单独复制图标，点击至少 48dp 高的整个地址区域复制，两个开关仍左右独立。
- 修复启停水滴中的图标继承按钮最小尺寸的问题：保留 88dp 控制区域，在内部居中使用 29.92dp 图标画布，恢复原设计比例。
- 按固定核心实际协议读取路由的规范十进制字符串计数器，拒绝非规范格式与溢出；资源调用取消时保留原取消异常，并等待实际 IO 任务退出。
- 服务四格随系统字体比例自然增高；修正首次声明与弹层遮挡的测试接线。TUN 测试传输使用可取消的非阻塞管道及统一截止时间，材质测试按实际连续圆角几何选取像素，保留原颜色门槛；这些检查仍须在新 Android 包上执行。

- 内置分流脚本采用 AEROVE Lite / meow 专版，沿脚本库一次初始化加入，并接入专用更新地址。保留已有编辑与配置选择；容量不足时保持旧库可读可编辑，释放空间后重试，用户删除后不自动回填。
- 校正 TUN 入包与出包的地址族策略：禁用 IPv6 时丢弃相应版本帧，非法 IP 首版本继续严格失败并保留无载荷诊断；本轮真实启动结果仍须 Android 验收。
- 编辑器撤销、重做与菜单可用状态接入已有布局就绪信号，避免连续内容切换访问尚未重建的行宽表；保留原历史和内容往返验证。
- 更新模块以唯一可等待的 IO 关闭 owner 取消并回收所有旧任务，再关闭自有 HTTP 客户端，保留首错和幂等，避免在主线程关闭 TLS。
- 资源任务提前结束时读取原 owner 的 join 分类，并以附加异常保留诊断；主异常、取消及清理规则不变，原实际退出原因仍待运行确认。
- 恢复首次启动失败时的原始核心错误和各阶段清理结果，保留 `runtimeCleanupFailed` 类型、取消与等待清理规则，避免后续清理错误覆盖诊断原因。此候选用于定位实际 Android 启动问题，尚不代表启动行为已修复。
- 对齐规则文件测试与固定 JNI 的完整异常消息，并修正资源下载测试的规范私有根路径；保留真实解析、代理传输、哈希和取消清理断言。
- 将大规则元数据、独立资源验证、准备预检及官方 MRS 预览/导出接入固定核心的严格 MRS 读取，并复用同一已打开文件进行有界解压。产品规则输入、只读预览和本地编辑/粘贴/保存保持 64 MiB 预算；固定核心官方 MRS 解压输出上限为 256 MiB，历史 `MRS!` 格式的 64 MiB 展开预算独立保留；另有 25 万条设备保护准入及单条文本规则 2,048 字节上限。当前 Lite 官方 MRS 路径仍未执行宿主 25 万条限制，候选测试包含 411,634 条读取；这是违反用户决定的待修阻断，不是已接受行为。Ruleset YAML 的 250,002 解析值上限对应最多 250,000 条 payload 加容器值；普通配置 YAML 的 100,000 值门槛是另一项限制。Native/Rust 与 Android 结果仍须按实际证据验收。详情见[核心记录](core/meow-migration.md#rule-preview-budget)及[官方 MRS 解码上限](core/meow-migration.md#mrs-decode-limits)。
- 导入、刷新与启动中的离线配置校验、完整转换及规则检查与导出各自持有原生离线 owner：取消在转换步骤之间以及 geo 文件读取、gzip/zstd 展开的每 64 KiB 生效，并等已开始的工作退出后才删除校验缓存或释放文件租约；zstd geo 数据改由宿主按固定核心同一解码器、上限与错误文字流式展开，读取遇系统中断时重试。JNI 导出新增逐描述符的严格构建门禁。Lite host119 的固定 Rust 核心真实编译已通过；provider 结构 epoch 回归仍未闭合。Native 测试、Android 取消时序与 RSS 仍待验，记录见[核心记录](core/meow-migration.md#offline-cancel-join)。
- 规则 provider 的本地文件、HTTP 下载和 HTTP 磁盘缓存改用同一个有界严格 MRS 读取器：文件按已打开的描述符读取，读取期间被追加、截断或改写即拒绝且不安装部分内容；含非法 UTF-8 域名叶子或倒置 IP 区间的上游 MRS 会指出字段与原因并拒绝加载，不再静默丢条目。标准版的官方 Mihomo 仍接受这类规则集，这是 Lite 的有意适配，记录见[核心记录](core/meow-migration.md#strict-rule-set-read)。Lite host119 的固定 Rust 核心真实编译已通过；provider 结构 epoch 回归仍未闭合。Native 用例、Android 与大规则验收仍待核。
- 仪表盘按最新共同契约采用右下双行指标和三胶囊状态。曲线/填充位于文字后方并连续覆盖，不加文字背后的局部遮罩、挖洞或衬底；极光前景字形仍可使用真实字形蒙版取色，以保留动态采样、抗锯齿和源透明度。实际 Android 像素仍待验。
- 读屏顺序：状态卡标题只读一次，状态芯片的圆点不再单独朗读；右下双行指标时依次读上传、下载，每个方向为「名称与速度」和「累计」两站，随后读出口摘要（IP 质量、运行时长、组织），最后是国旗重试、IP 与启停按钮；指标附加到正文下方时在启停按钮之后读出。单独速度卡为标题加每个方向两站。
- 状态卡与速度卡文字按标准版对齐：速率单位在各语言都为「/s」（中文、俄文原为「/秒」「/с」；连接页与请求页共用这两个文案），俄文「下载」改为「Загрузка」；状态卡与单独速度卡的流量改用标准版格式，按 1024 进位显示 B、KB、MB、GB、TB，保留一位小数并去掉末尾的零（如「4 KB」「1.5 MB」，原为「4.0 KiB」，部分语言还用逗号作小数点）；组织没有名称时显示「AS」加 ASN；挂起时运行时长显示「—」，超过 999 小时显示「999:59:59」；出口检测失败时地址处显示「检测失败」，下方提示「点击图标重试」；IP 类型未知或查询失败时摘要都显示「类型未知」。启停提示为「启动」「暂停」「挂起中…」，国旗提示为「重试」，中文运行时长标签为「运行时长」，中、日、韩、西班牙文累计文案为「累计」「累計」「합계」「Total:」。
- 本地规则与只读规则预览统一采用用户确认的 64 MiB 设备保护上限，规则的打开、编辑、粘贴、批量替换与保存共享会话预算；普通配置编辑仍采用原上限。
- 启停按钮按标准版行为调整：有配置即可用，并按最新意图读出和执行；启动中的运行时长从点击意图开始读出；就绪后沿用同一起点，取消或失败后清零。启动中读「暂停」，点按经现有 `LiteController.disconnect`（`platformEntryGate.cancelStart`、`invalidatePendingStarts`）取消待定的启动；断开中读「启动」，点按重新启动；导入、更新等后台任务不再使按钮停用。图标随意图切换，按钮只保留一个读屏站点，同一节点提供点击与输入焦点；触摸长按仍显示普通提示，不向 TalkBack 增加标准版没有的长按动作。
- 读屏按标准版读法调整：国旗读「重试」，画出国旗时并读国家代码，重新检测已知出口或查询 IP 质量时也保留代码，此时国旗为停用；出口 IP 不再读作按钮，并在地址后读出标准版提示「出站 IP详情」；运行时长、组织与速度按「标签、换行、数值」读出，累计只读一次（原为说明与数值各读一遍）；尚无已知出口或上次出口时（未检测、首次检测中或 VPN 停止），地址与组织的值不朗读；重新检测已知出口或首次检测时显示的上次出口，按标准版读出地址与提示，检测失败时读「检测失败」与「点击图标重试」。检测中的转圈、地址与质量占位以及上次出口提示只作绘制，质量占位也不再可点，出口详情仍从地址打开。
- 两版记录：标准版入口为 `current_outbound.dart`（`_CountryBadge`、`_ExitRow`、`_IpChips`、`_Cells`、`_StartToggle`）、`traffic.dart`（`OutboundTrafficFigures`、`_SpeedTile`）、`setup.dart`（`setRunning` → `_claim`）与 `style.dart`、`num.dart`（`dashboardTraffic`）；Lite 入口为 `OverviewScreen.kt`（`OutboundStatusCard`、`CountryBubble`、`MissingExit`、`StatusSpeed`、`SpeedTile`、`StartBubble`）、`DashboardFigures.kt`（`dashboardTraffic`、`formatUptime`）与 `IpQualityPanel.kt`（`IpQualityChips`）。出口数据流：出口来自 `OutboundProbe`，质量来自 `IpQualityFeature`，启停仍由 `LiteController.connect`、`disconnect` 与 `LiteVpnService` 的意图代数收敛；点击时间经服务 Intent 送入 `VpnCoordinator`，请求、Starting、Running 共用同一起点，`LiteController` 仅在前台采样，停止/失败清理计时。标准版朗读由 Flutter 3.47.6（`RawTooltip` 的 `Semantics(tooltip)`、`BaseRoleConfigurator` 的名称与 tooltip 映射）和 TalkBack 229212fd（`TreeNodesDescription`、`RoleDescriptionExtractor`，默认「状态、名称、类型」顺序）按源码推出，尚无标准版语义测试或实听，两版是否逐字一致也还没有模拟器或设备结果；Lite 依 Compose ui-android 1.12.0 字节码（`emitFakeNodes` 伪子节点、`clearAndSetSemantics`）实现。Android 测试改用节点提供器实际给出的伪子节点与同一 TalkBack 规则计算站点和朗读，逐字断言正常、检测中、重新检测、上次出口、质量查询中、检测失败、停止、挂起、启动中运行时长、无名称组织与单独速度卡，覆盖启动中取消、断开中重新启动和无配置时停用，按钮不提供长按读屏动作，普通触摸长按仍显示提示；输入焦点往返改在键盘模式下断言；质量面板测试改从地址打开详情，并断言占位没有点击动作。判定与朗读模型的 24 个 JVM 用例在本机通过，23 个变异体全部被测出，另 1 个等价变异体说明在案；流量与运行时长格式另有 3 个 JVM 单元测试在本机通过；Android 测试本地只完成编译，须在 Lite CI 的 API 33 模拟器上运行。本轮修复不新增内核例外。
- 以下仍与标准版不同，均无核心依据，记为首发阻断而非可接受的差异，须由仪表盘、出口检测或对应负责人收敛：质量摘要为可点按钮并读作「质量、类型、等级」，标准版为不可点的「类型」与「质量 等级」两枚芯片，加载时为骨架；Lite 另有「正在连接…」「正在断开…」「连接失败」状态芯片（标准版按意图显示运行中或未运行）、每次启动都会显示并朗读上次出口（标准版仅首次恢复暂定值）、上次出口提示、检测中可见的「正在检测出口地址…」「查询中…」，以及会被朗读的监听与出口错误说明；检测中 Lite 以转圈代替晃动的国旗，国旗与 IP 没有长按提示；标准版国旗显示代码时，TalkBack 会在末尾再读一次提示「重试」，Compose ui 1.12.0 没有 tooltip 语义，Lite 缺这一段；VPN 未运行（停止、启动中、断开中或失败）时 Lite 国旗停用，标准版仅在检测中停用；VPN 停止时标准版仍直连检测出口，Lite 不检测，地址与组织显示「—」；启动中 Lite 的飘带动画仍按实际阶段静止；运行时长与组织在标准版为标签在上、数值在下的两格，Lite 为单行且组织不显示标签，卡外的连接、请求、配置用量等流量仍为 KiB 格式，出口详情面板的中文标题为「出口 IP」（标准版「出站 IP」）。
- 网络控制卡整合出站模式、VPN 和局域网代理；两个开关在同一行左右布置，局域网地址与端口在独立整行居中，点击该行复制。
- 网络概览卡整合服务可用性及连接、请求、DNS 查询摘要，保留独立详情入口。原控件显隐、顺序及布局编辑通过呈现层分组保留，配置和代理组继续独立。
- 接入官方共享流量采样和原生计数接口，按真实采样版本维护曲线段；页面失活、后台、暂停或停止时停止呈现，恢复后不连接旧段。统计未知时保留未知状态，不用零值冒充已采集。
- 修复出口切换后的代理组缓存时序、观测窗口首次激活确认的状态污染，以及许可证生成与 lint 任务的依赖和英文文案缺失。

- 接入真实 TCP/UDP 生命周期与 DNS 上游、缓存和来源事件，按恢复水位续接；补齐同会话 resolver 绑定、UDP 规则字段、取消清理及有界事件窗口，复用原单采样源。
- 补齐 Android 核心的静态 C++ ABI 链接，并在 ELF 验收前置拒绝未解析的强运行时符号；实际新库装载以本轮设备验收为准。
- 编辑器搜索结果改为在上游发布完成后单次刷新，测试等待真实文档布局完成再输入；保留原内容断言与时限。
- 根据同轮 release/test 映射、使用记录及实际 DEX 引用精确保留测试所需接口；补齐隔离参数与模拟器失败证据采集，不改变生产渲染入口。

- 服务与模式格允许大字体自然增高，空服务区不再预留 108dp 空白。国旗去除圆底、阴影和硬裁切，仅外缘轻微渐隐。
- 接通订阅节点真实投影与一般策略组，保持候选身份、取消及最终提交门禁；接受后再持久化缓存，关闭时等待实际写任务。
- 规则文件内容校验错误统一保留具体字段与解码原因；补齐 release 测试所需的八个精确成员接口。保留首个原生测试异常，清理失败作为附加错误并继续恢复本测试资源。
- Android 取证增加帧提交时序，以及指定 IP 质量流程的阶段与线程证据；原业务断言、画质、动画策略和验收门槛不降低。

- 针对上一候选实际 Android 图中紧凑指标落到卡片下方的问题，改用原前景的实测占用矩形判断右下双行指标是否碰撞；普通字号的右上位置、原正文坐标和卡高仍由 Android 断言验收，不能以附加到下方作为通过。

- 接通 provider 自动健康检查的运行时任务、业务使用触发与网络切换时的上下文更新；保留单一任务所有权、取消等待、旧结果失效和来源提交门禁。
- 从真实预 R8 app / AndroidTest classfile 推导精确保留规则，保留生产混淆；最小工具用例已通过，完整 AGP 任务图及新 APK 的真实接口调用仍待本轮 CI 验证。
