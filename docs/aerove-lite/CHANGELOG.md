# AEROVE Lite 变更记录

## 待发布

共享 Flutter 首发下一修复候选为 **0.2.0-beta.7（安装编号 39）**，接续原候选 38 的启动及订阅兼容问题。原构建 #290 的两种 ABI 安装包及失败证据继续保留，不作为本候选原包。新增快捷入口真实发布、安全启动诊断和规则原始载荷检查与进程内受控发布；本候选仍须新真实构建、完整必要 CI、Android 和手机验收。本候选未接受、未发行。SQL/raw 崩溃恢复日志、运行中保连接更新、合集界面及真实用量统计等首发剩余工作继续按共同契约完成，不能以本候选或预检代替交付。

- Android 快捷入口经既有发布器创建，保留系统真实返回值，沿用标准版图标和实际启动／停止入口；不再直接拒绝初始化请求。
- 启动失败保留有限阶段、错误码及 I/O 类型，清理结果单列；原异常、取消及退出顺序保持，诊断不输出原始错误正文、配置或凭据。
- 规则库复用共享请求策略和真实 Meow 检查器，保留已检查的原始格式，不伪造 MRS；独占候选与来源写入门协调 SQL/raw 的提交、回滚和后续意图，未确认读取结束的候选继续保留。

- 订阅导入及提供者载荷按固定 Meow 核心能力生成兼容投影，保留原始来源并报告过滤的协议和数量；不支持的节点从有效运行投影及其引用中移除。标准版沿用自身 Mihomo 能力和相同共享入口。
- `dns.ipv6` 保留省略、显式 true 和 false；已启用的主／代理 DNS 使用根 IPv6 与该值共同决定的结果，显式 hosts、缓存及 fake-IP 的既有行为按固定核心验证，不把其它不支持 DNS 字段静默删除。
- 节点选择经来源写入门及数据库队列仅更新所选列，等待实际提交并保留较新的来源绑定；各组意图独立结算，失败回滚后也核对完整 metadata，旧请求不回滚新选择。标准版无所选配置时的核心调用保持。
- 原生已持久确认的来源事务终态可保留后来节点选择并收尾；未决事务继续要求完整旧来源证明、真实运行图恢复及文件／行 CAS，第三值不覆盖。
- Android UI 验收等待页面及真实语义点击稳定，保留原像素、光学位移和材质门槛。诊断纯函数独立于 Flutter 嵌入类，限量记录安全方法名、异常类型和栈帧。

- 只规范化 Android 提供的可信私有根，保留下级目录和共享配置 XML 的普通文件、无符号链接及归属校验；原配置内容、XML 解析和缺失错误保持。新增可信系统根别名读取与下级链接拒绝回归。标准版没有该 Meow 原生读取入口，无需改动其应用实现。

- 合法 lwIP 源配置在导入阶段无需尚未建立的 Android Builder 收据，源字段和能力继续校验；实际激活、managed 和 prepared 路径保留原有 TUN 协调与收据要求。
- 配置校验异常保留具体字段和原因，不再误报为通用 Meow 方法失败；挂载前的未分类故障记录受限方法、异常类和栈帧，不记录请求内容或凭据。
- 非空旧或部分设置仅为缺失的 Meow TUN 字段补核心默认，显式值、主题、严格解析和迁移失败恢复语义保持。
- Mieru 等固定核心没有出站实现的协议按兼容投影过滤并报告，原节点和源配置保留；有效投影仍严格校验支持协议、字段和引用。

- Lite 初始 Android 预设不再注入固定 Meow 不支持的全局 TCP keepalive 调整。历史预设元组按受限兼容迁移约定处理：仅既有 fresh/complete 设备记录且精确匹配旧元组时恢复中性值，记录本版判断；其余设置、主题及人工非默认值保持，显式不支持的字段继续报错。
- 配置构建或真实 applied 记录失败时，保留有效 YAML、已应用状态和原始错误，不再继续发送缺少记录的 setup 请求。
- 待校验文件放在可信私有 home 的临时子目录，覆盖订阅下载与内存配置校验入口；原生普通文件、私域和无符号链接限制保留。
- Lite 内存页使用应用与内核共享进程的真实 RSS，只统计一次，保留详情与清理入口；不显示伪 Core 零值或 Go 堆／GC 指标，不把 PSS 当作 RSS。两版共同清理可回收图片缓存，Lite 明确提示 RSS 未必立即下降；标准版继续真实 Core GC，并检查失败确认。
- 首次内存采样前保留卡片布局空间，隐藏未取得的指标及详情操作，避免新增卡片入场后再突然变高；重新生成实际 SetupAction 来源哈希。

- 首次创建配置时根据物理内存、Android 媒体性能级及 shader 支持选择保守的材质和底图推荐，随配置保存；升级、迁移、已有配置及用户后续修改均保留，不重复覆盖。
- 关于页复用已按标准版前景范围对齐的现有品牌资源，统一飘带占比、位置和留白，保留 Lite 原黑色材质和白色底图；96dp 连续圆角矩形没有额外外框或内缩底座，桌面资源保持。

- Lite Android 的平台私有根统一为实际路径，供服务、核心初始化和配置文件共用；继续拒绝外来路径重定向，不改变标准版路径行为。
- 首次无选中配置也经真实默认配置生成器处理全局 DNS、hosts、TUN 和 Geo 设置，并由原生核验实际空选择；未选中的库记录保持原样，已有选择仍须完整匹配。

- 初始化服务前也能保存最新共享状态，保留可选 VPN 和 setup 字段；初始化及同一引擎重建时完整应用，取消、失败或分离不覆盖已接受状态。单条请求预算和原来源协调、运行态兼容校验保持。
- 迁移目标和运行期业务来源以只读方式核验 SQLite 数据，并拒绝读取期间的其他连接提交；保留原表、行数、内容哈希、文件和来源断言，避免 Android 将延迟事务转成独占写事务。

- 旧数据导出与大响应文件直接使用目标路径的 POSIX 权限属性视图，设置并读回原有私有权限，避免 Android 的 FileStore 安全限制；不放宽锁、恢复、源校验或错误处理。现有实际导出和响应文件回归补充权限断言。

- 迁移错误保留原字段和失败语义，补充不含消息、URL、密钥或源内容的有界异常类型与栈帧；保留恢复日志拒绝回归并增加诊断隐私回归。

- 旧数据迁移从真实保存设置为每个保留资源包重建 TUN 校验上下文，继续核验完整资源、来源和历史槽位；不改写旧数据，也不放宽正常启动的策略校验。新增真实历史资源包导出与 Kotlin→Dart 导入回归。

- 本地节点与规则库只保留来源已验证、且未被脚本修改的应用拥有文件引用，避免指向尚未物化的缓存；脚本改名、改类型或改路径仍受隔离，删除的引用不复活。原生迁入的 domain/ipcidr、YAML/text 规则保留实际源文件格式与路径。
- 没有实际持久化编辑时保持原有提供者格式容错，实际编辑继续严格校验；补充共享真实模型与文件读回回归，不放宽 Android 或核心验收门。
- 原生旧数据迁移统一使用平台可信私有根的实际路径身份，允许系统根别名，同时继续拒绝根内链接及断开的状态链接；保留源文件、迁移校验和取消重试。新增真实 Kotlin 导出至 Dart 导入的回归接线，实际执行及新 APK 验收待完成。

- 配置生成沿真实数据库与 Node 脚本进入带类型的 DNS、Geo 和资源事务；两种核心的 DNS 来源恢复回归通过，损坏的来源凭据整体丢弃，普通配置字段仍可逐项恢复。
- Geo 发布异常清理同时保护持久化 desired 与 lastApplied 引用的实际资源路径，避免新配置或停止会话清理掉仍可恢复的旧资源；相关五项 JVM 回归通过。
- 共享 Flutter 启动流程调整为先保持私有会话，完成同一核心会话的节点恢复与读回后，再恢复控制器并激活 TUN；复用同一预建 FD，取消时仍等待原生退出再释放。相关 JVM 回归通过。
- 源配置 `profile.store-selected` 的三态沿标准版现有产品策略交给同一 profile SQL 选组记录管理，并绑定原来源证明；源准入与运行态校验分开，未消费的运行态字段继续拒绝。
- URLTest 的失效启动历史保留原始 fixed 名称，当前节点继续自动选择；显式选择未知成员仍拒绝。复用固定 meow 的启动内存恢复接口。
- 共享客户端接入单项及批量订阅更新取消，等待真实下载、验证和暂存清理，保留已完成项、旧文件及较新编辑；Android 实际取消与恢复仍须验收。
- 内置专版脚本原样同步 Smart-Config-Kit 固定 `5e28b84fa5161c67222b1b12f71732a2e7b80fae` 的 `v6.0.21-meow.8`；离线实际投影和资源读回已完成，旧用户正文保持用户可控更新，QuickJS/JNI 与实际配置准入仍须验收。

### 0.1.0-beta.25（安装编号 25）

最近原生界面候选为 **0.1.0-beta.25（安装编号 25）**；包名 `dev.aerove.lite`、独立签名与 preview 通道沿用。原 run `40859085935`（#163）、source `cf28637c8dc850dd634447df02630e893a99a258` 已构建一次；完整 CI 为 393 项通过、44 项失败、2 项未执行，另十二图矩阵 12 项通过；随后手机验收失败，本候选未接受、未发行。2026-10-29 用户决定改为共享 Flutter 客户端 UI + meow-rs，该迁移目标尚未构建或验收；以下条目记录旧候选源码，不代表 Flutter Lite 已完成。真实光学、帧表现和网络取消/恢复等完整验收仍未闭合；满足自身完整契约后独立发行。

- **融合编辑：** 正常页、编辑页、拖拽与恢复列表共用融合卡片，排序、隐藏和恢复按整组操作；未操作的旧成员选择与顺序保留。有效操作即时保存，返回与完成仅退出；预览隔离内部指针、键盘及读屏业务动作，外层编辑操作保持可访问。
- **主题名称：** 主题色选项统一更名为“经典单色”，同步七种语言。
- **局域网地址：** 融合卡显式开启局域网代理后，成功提示并复制局域网 IP 与端口；失败、取消或过时结果不触发复制，卡片保持原布局。
- **统计刷新：** 实时连接、最近请求和 DNS 查询在前台按秒刷新，后台或短暂失焦立即暂停，恢复补最新；不改变详情、流量与动画的既有节奏。
