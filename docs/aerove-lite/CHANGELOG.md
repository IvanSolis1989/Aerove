## 待发布

下一应用候选为 **0.1.0-beta.24（安装编号 24）**；包名 `dev.aerove.lite`、独立签名与 preview 通道沿用。新源码 APK 尚未构建，本候选未接受、未发行。真实光学、帧表现和网络取消/恢复等完整验收仍未闭合；满足自身完整契约后独立发行。

- **融合编辑：** 正常页、编辑页、拖拽与恢复列表共用融合卡片，排序、隐藏和恢复按整组操作；未操作的旧成员选择与顺序保留。有效操作即时保存，返回与完成仅退出；预览隔离内部指针、键盘及读屏业务动作，外层编辑操作保持可访问。

- **局域网地址：** 融合卡显式开启局域网代理后，成功提示并复制局域网 IP 与端口；失败、取消或过时结果不触发复制，卡片保持原布局。新交互仍待 Android 验证。

- **曲线延续：** 切页或暂时离开前台时保留已有上下行曲线，恢复后衔接最新采样；实际连接重启仍使用新曲线。
- **国旗定心：** 后台按系统彩色字形的可见像素测量并缓存透明图像，居中绘制并保留原边缘渐隐；Android 字形和密度验证待新候选 CI。
- **更新备用源：** GitHub API 返回 HTTP 403 或 429 时，使用固定官方站点的完整发行数据；备用数据须覆盖当前安装版本，原安装包、校验和及来源校验继续生效，取消和失败不会显示为已经最新。
- **专版脚本：** 原样同步 Smart-Config-Kit 固定 `c18c314d94206eb6724d235ca0d590c3e14e9121` 的 `v6.0.21-meow.7`，脚本、来源、同批 README、运行时完整性与测试输入一同更新；离线 Node 执行与 158 文件读回已完成，真实 Android 和新 APK 尚待验收；FCM 使用 Google 服务出口，已有用户脚本正文保持用户可控更新。
