# AEROVE 标准版

[文档](../README.md) / 标准版

工程位于 [apps/aerove](../../apps/aerove/)，采用 Flutter 与 Mihomo；Android、Windows、macOS、Linux 共用产品工程。

## 开始使用

1. 在[项目首页](../../README.md#download)选择稳定版或公开预览版，阅读发行说明后安装。
2. 导入自己准备的配置或订阅，选择出口与模式并启动连接。
3. 调整设置前先阅读下方说明，区分新安装默认值与已有用户设置。
